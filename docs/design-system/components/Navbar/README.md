Top bar. App variant: wordmark, links, notifications, theme toggle, avatar. Marketing variant: wordmark, links, "Log in" ghost, "Start free" primary.

Toggle `is-compact` below 960px (menu button replaces links); `is-open` shows the panel. Mark the current link with `aria-current="page"`. Signed-in app pages have no navbar on desktop (the sidebar is the navigation). At 640px and below they use the app variant, `navbar navbar--app is-compact`: 90% of the viewport wide, centred, slightly see-through (80% `surface` over a backdrop blur), with a border and `radius-lg` bottom corners (the same as the sidebar), holding the wordmark on the left (to the shop overview, or to the dashboard outside a shop) and the menu button that opens the sidebar drawer on the right. Log out is not in the bar; it lives on the Account page. Customer booking pages use a minimal bar: wordmark and the shop name only. Don't pair a navbar with a sidebar for the same navigation.
