Top bar. App variant: wordmark, links, notifications, theme toggle, avatar. Marketing variant: wordmark, links, "Log in" ghost, "Start free" primary.

Toggle `is-compact` below 960px (menu button replaces links); `is-open` shows the panel. Mark the current link with `aria-current="page"`. App pages outside a shop (dashboard, account) use the app variant, `navbar navbar--app`: 90% of the viewport wide, centred, slightly see-through (80% `surface` over a backdrop blur), with a border and `radius-lg` bottom corners (the same as the sidebar), holding the wordmark (to the dashboard), a spacer, then the Account button in `navbar__actions`: icon and label on desktop, icon-only with `aria-label` and a `tooltip tooltip--end` when `is-compact` (`aria-current="page"` on /account). Log out is not in the bar; it lives on the Account page. It fits 360px as is; `is-compact` only tightens height and padding. Shop pages use the same bar at 640px and below, with the wordmark (to the shop overview) on the left and the menu button on the right. Customer booking pages use a minimal bar: wordmark and the shop name only. Don't pair a navbar with a sidebar for the same navigation.
