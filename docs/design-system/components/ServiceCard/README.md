Selectable card for one service: name, short description (2 lines), duration, price, selected check.

Render as `role="radio"` in a `role="radiogroup"`; one choice per step. Selected: accent border, tint and a check, so state never depends on color alone. Unavailable services are dashed, muted and not selectable, with a reason badge. The consumer provides name, description, minutes and a locale-formatted price.
