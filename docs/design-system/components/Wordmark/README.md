The BeBooked logo as live type: "Be" in `brand-accent`, "Booked" in `text`, set in Gasoek One. `brand-accent` belongs to the colour set, so inside the app "Be" is orange in Original, grey in Black & white and magenta in Purple; on public pages it is always orange.

Use `<span class="wordmark"><span class="wordmark__be">Be</span>Booked</span>` in the navbar, sidebar, auth card and footer; `wordmark--sm` (18px) in compact bars, `wordmark--lg` (48px) on the landing hero. Never set headings in Gasoek One and never recolor "Be" to a state color.

Inside running text or a heading, add `wordmark--inline`: the logo face at the size and colour of the text around it. Add `wordmark--muted` in paragraphs so "Be" keeps the text colour too.
